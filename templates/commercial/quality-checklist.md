# Delivery quality checklist

- [ ] Scope matches the proposal.
- [ ] Names, URLs, figures and dates verified.
- [ ] Sources recorded where relevant.
- [ ] No unsupported claims.
- [ ] No private data exposed.
- [ ] Language and formatting reviewed.
- [ ] Links and files open correctly.
- [ ] Deliverable stored in the client folder.
- [ ] Actual time and direct cost recorded.
- [ ] Handover message reviewed by a human.
