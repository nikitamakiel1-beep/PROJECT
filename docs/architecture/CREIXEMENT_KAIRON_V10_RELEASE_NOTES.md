# Kairon V10 — Business Portfolio Release Notes

This release changes the organizational model without changing the constitutional authority model.

- Kairon is explicitly the Chief Operator across the whole Creixement operation.
- Business becomes the portfolio workspace; Tectum is the first operating project inside that portfolio.
- A Venture Foundry converts evidence-linked opportunities into governed project recommendations, bounded internal experiments and, only behind the supervised economic L2 gate, reversible incubating projects.
- Foundry projects cannot become operating/scaling from forecasts or scores alone.
- Portfolio state is added to Kairon's supervisory proof snapshot and deterministic digest.
- A six-hourly `business.venture_foundry_cycle` is registered under the chief-orchestrator runtime identity.
- No new browser mutation authority or L3 autonomy is introduced.
