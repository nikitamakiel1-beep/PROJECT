# System-of-record policy

## GitHub

Versioned source and reproducible definitions only: website, schemas, automation code, public content, templates, architecture decisions and stage handoffs.

## Google Drive

Operational and client information: CRM spreadsheet, contacts, contracts, inputs, research, deliverables, feedback, invoices and compliance records.

## Linear

Execution control: projects, issues, milestones, dependencies, owners, dates, blockers and evidence links.

## Prohibited duplication

- GitHub must not become a CRM.
- Linear must not become the document archive.
- Drive must not become the authoritative source-code store.
