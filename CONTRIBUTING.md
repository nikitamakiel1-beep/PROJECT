# Contributing

1. Work from a dedicated branch linked to a Linear or GitHub issue.
2. Keep each pull request bounded to one stage or one corrective task.
3. Update tests and documentation with code changes.
4. Do not store operational records in GitHub.
5. Every orchestration-stage pull request must include:
   - implementation,
   - stage report,
   - next-stage instruction,
   - updated orchestration state.
6. Use squash merge after checks pass.
