# International Growth Venture

Dedicated repository for the website, CRM schemas, automation source, reusable service templates and recursive stage handoffs.

## Repository boundary

- GitHub stores source code, schemas, templates and evidence-safe stage documentation.
- Google Drive stores the CRM, client records, operational evidence and deliverables.
- Linear stores execution, dependencies and decision gates.

Do not commit credentials, deployment URLs, spreadsheet IDs, CRM exports, client information or private research.

## Status

The active implementation is developed on isolated stage branches and reviewed before any merge to `main`.
